# Project screenshots
Drop screenshots here using the `image` path defined in `src/data/projects.js`,
for example `eclaims.png` for the `/images/projects/eclaims.png` entry.
Any missing file falls back to a generated gradient cover, so the layout stays
intact until the real screenshot is added.
Recommended: 1600x1000 (16:10), PNG or WebP, under ~300 kB.
